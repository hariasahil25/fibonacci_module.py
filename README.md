# Fibonacci Module in Python

This Python program demonstrates how to define a module for generating Fibonacci numbers and import that module into another program.

## Files Used

- `fibonacci_module.py`
- `main_program.py`

## Operations Performed

- Creating a module
- Defining a Fibonacci function inside the module
- Importing the module into another program
- Calling the function from the imported module

## Python Code

The module file contains a function named `fibonacci()` that prints Fibonacci numbers.  
The main program imports the module and executes the function.
